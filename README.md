# STRAIN

> A diagnostic tool that treats unfair rental contract clauses as a communicable disease.

STRAIN identifies which known "strain" each clause in your document descends from, how that strain has behaved historically, and what wording has neutralised it. Built for Indian residential rental agreements.

**The corpus is synthetic.** Relationships shown are textual kinship, not proven copying. See `EVALUATION.md` for measured accuracy metrics.

---

## Setup (5 commands)

```bash
# 1. Install Python dependencies
pip install -r requirements.txt

# 2. Install frontend dependencies
cd strain/frontend && npm install && cd ../..

# 3. Generate synthetic corpus + build database (downloads ~90 MB model on first run)
python scripts/seed_corpus.py

# 4. Start the app (both backend + frontend)
make demo

# 5. Open browser
# Backend:  http://localhost:8000
# Frontend: http://localhost:5173
```

> **First run**: `seed_corpus.py` downloads `all-MiniLM-L6-v2` from HuggingFace (~90 MB) and caches it locally. All subsequent runs are fully offline.

---

## Individual commands

| Command | What it does |
|---------|-------------|
| `make backend` | Start FastAPI server on :8000 |
| `make frontend` | Start Vite dev server on :5173 |
| `make demo` | Seed corpus (if needed) + start both servers |
| `make test` | Run pytest suite |
| `make evaluate` | Run `scripts/evaluate.py` → writes `EVALUATION.md` |
| `make seed` | Re-generate synthetic corpus (clears existing DB) |

---

## Real document ingestion (roadmap item)

The demo corpus is synthetic. To ingest real documents:

```bash
# Drop PDF/DOCX/TXT files into data/real/
# Then:
python scripts/ingest_real.py
```

This merges real documents into the corpus as an additional generation. The tool ships with zero real files present.

## Architecture

```
strain/
  backend/      FastAPI — pipeline, providers, store
  frontend/     Vite + React + TypeScript + Tailwind
  scripts/      seed_corpus.py  ingest_real.py  evaluate.py
  data/         ground_truth.json  outcomes.seed.json  strain.db
  tests/        pytest suite
```

**Stack**: Python 3.11+, sentence-transformers, HDBSCAN, SQLite/SQLModel, Vite, React 18, TypeScript, Tailwind CSS, D3 v7, Recharts.

No Docker. No Redis. No cloud services. No paid API key required.

---

## Evaluation

`EVALUATION.md` is generated by `make evaluate` and contains real measured metrics:
- Clustering ARI against ground truth
- Edge accuracy and direction accuracy  
- Held-out diagnosis accuracy
- Honest notes on what doesn't work yet

## Legal

This tool provides information about textual patterns in documents. It does not provide legal advice. All litigation history records are marked `illustrative`. See the HandoffPanel in the app for guidance on consulting a qualified lawyer.
